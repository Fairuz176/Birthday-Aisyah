BIRTHDAY WEBSITE FOR AISYAH AINI
===========================

ISI FOLDER
----------
index.html     Struktur website
style.css      Desain, warna, dan animasi
script.js      Tombol, navigasi, pemutar musik, dan galeri
assets/        Tempat foto dan file musik

TAMBAHKAN FOTO
--------------
Masukkan 4 foto yang boleh digunakan ke folder assets, lalu beri nama:
  aisyah-1.jpg
  aisyah-2.jpg
  aisyah-3.jpg
  aisyah-4.jpg

Jika hanya punya satu foto, kamu bisa menggandakan foto itu sementara atau
mengubah HTML agar menggunakan nama file yang tersedia. Gunakan foto yang
Aisyah nyaman untuk dibagikan.

TAMBAHKAN MUSIK
---------------
Masukkan file audio MP3 yang kamu punya izin untuk menggunakannya ke:
  assets/birthday-song.mp3

Musik hanya mulai saat tombol Play ditekan, karena browser HP umumnya
memblokir pemutaran otomatis.

JALANKAN DI VS CODE
-------------------
1. Buka folder birthday-aisyah di VS Code.
2. Pasang ekstensi Live Server.
3. Klik kanan index.html > Open with Live Server.
4. Tes seluruh tombol dan tampilan di HP/komputer.

PUBLIKASIKAN GRATIS DENGAN GITHUB PAGES
---------------------------------------
1. Buat repository baru di https://github.com/new
   Nama: birthday-aisyah
   Pilih Public.
2. Unggah isi folder proyek ini ke root repository. Pastikan index.html
   ada di root, bukan di dalam folder lain.
3. Buka Settings > Pages.
4. Pada Build and deployment pilih "Deploy from a branch".
5. Pilih branch main dan folder /(root), lalu Save.
6. Tunggu publikasi. URL biasanya berbentuk:
   https://NAMA-USERNAME.github.io/birthday-aisyah/
7. Buka URL itu dari HP dan uji semua foto, tombol, serta musik.

BUAT QR CODE
------------
1. Salin URL website GitHub Pages yang sudah aktif.
2. Buka https://www.qrcode-monkey.com/
3. Pilih URL, tempel tautan website, lalu buat QR Code.
4. Unduh PNG atau SVG.
5. Uji dengan HP lain sebelum dicetak/dikirim.

CATATAN PRIVASI
---------------
Repository Public berarti file foto dan musik dapat diakses publik.
Jangan unggah foto sensitif atau materi yang penerima tidak nyaman jika
dilihat orang lain. Jangan masukkan informasi pribadi atau rahasia.

ANIMASI TAMBAHAN
----------------
Versi ini memiliki kupu-kupu yang terus melintas berulang, hati yang naik dari bawah layar, dan kilau yang berkedip terus-menerus. Animasi berjalan otomatis selama website terbuka.
